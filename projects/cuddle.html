Case Study

Cuddle Market (Team → Solo)

반려동물 용품을 중고로 사고파는 서비스입니다. 상품 등록과 검색, 실시간 채팅과 알림, 커뮤니티, 관리자 화면을 갖췄고, 웹은 운영 중이며 Android 앱은 비공개 테스트 중입니다.

Live ↗ Admin Demo ↗ GitHub ↗
개요
협업 프로젝트(프론트엔드 4명, 백엔드 3명)로 시작했고, 팀에 완성을 제안해 함께 이어 가다가 이후 혼자 맡아 끝까지 완성했습니다. 지금은 Next.js 웹과 React Native 앱이 공통 코드를 나눠 씁니다.
기간
개발 2025. 08 ~ 2026. 11
역할
  • V1 (Vite, 2025.08 ~ 2026.01): 중간에 프론트엔드 팀장을 맡아 커밋과 PR 규칙, 코드 리뷰 방식을 팀과 함께 정함. 팀원이 떠난 뒤 혼자 완성해 배포
  • V2 (Next.js + Expo, 2026.02 ~ 2026.09): Next.js App Router로 옮겨 배포하고 운영. 관리자 화면, 서버 감시 장치, Android 앱, 웹과 앱의 공통 패키지, CI를 만듦
  • 백엔드: 현직 백엔드 개발자가 만든 서버 기본 구조 위에 AI 도구와 함께 지도 장소 API, 로그인, 상품, 알림, 채팅 기능을 더함
기술
Next.js 16, React 19, TypeScript, React Native (Expo), Zustand, React Query, WebSocket (STOMP), SSE, pnpm 모노레포, Vitest, GitHub Actions, Vercel 백엔드 (AI와 함께 구현): Java 21, Spring Boot 3, Spring Data JPA, Spring Security (OAuth2), WebSocket (STOMP), Redis, MySQL
